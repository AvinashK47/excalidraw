# Brag Plan: SyncBoard Real-Time Collaborative Canvas

## Planning Rubric
1. **What is it?**
   A high-performance real-time collaborative whiteboard with infinite-feel canvas, 9 vector drawing tools, sub-10ms WebSocket peer sync, multi-user cursor presence, and dual-layer late-joiner state recovery backed by PostgreSQL 16.
2. **Who is it for?**
   Engineering teams, remote collaborators, and designers who need an instant, unencumbered canvas to brainstorm architectures and diagrams together without lag or desync.
3. **What sets it apart?**
   Turborepo monorepo architecture, dedicated Express HTTP backend for room state and auth, high-throughput WebSocket sync server, and write-through cache ensuring late joiners never lose old shapes.
4. **Visual hook:**
   Neon vector geometry intersecting on a dark obsidian grid with multi-user live cursor tags.
5. **Key UI to show:**
   The SyncBoard room interface, floating pill toolbars, color palettes, and real-time cursor presence.
6. **Tone:**
   Polished, snappy, collaborative product launch.
7. **Format & Duration:**
   Landscape 1920x1080 @ 30fps, 18.0 seconds.
8. **Audio Arc:**
   Upbeat rhythm (`happy-beats-business-moves-vol-12`), crisp tool clicks, smooth fade-out.
9. **Share Caption:**
   "SyncBoard: Real-time collaborative canvas. Zero-latency WebSockets, vector precision, and PostgreSQL 16 persistence."
